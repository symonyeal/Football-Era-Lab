# Prior Era Eleven game

Archived 2026-10-06 after the replacement data coverage gate passed. This version preselected players on a Python server and generated opponents. The active build uses manual club-decade drafts and a shared JavaScript engine.

The original engine, browser, data, tests, notebook, documents, requirements and CI configuration are preserved here. The archive includes its own historical manifest; active data/manifest.json describes v2. Documentation migration is listed in DOCUMENTATION.md. Archived tests and old environment pins describe that version and are outside current v2 CI. No raw downloaded sources or credentials were added to this archive.
