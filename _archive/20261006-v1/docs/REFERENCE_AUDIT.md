# EraBall browser audit, 2026-10-05

The inspected reference is [EraBall](https://eraball.com/), displaying v3.1. This audit used unsigned, independent persistent Chrome profiles and Playwright 1.59.1. No account was created, purchase made, public matchmaking entered, or message sent to another person. A private room was created and joined by the auditor's second browser.

Each numbered JSON file records the visible page text, controls, browser storage and capture time; the matching PNG records the viewport or full page. Some early snapshots caught loading or the unchanged home screen while lazy components loaded. Those are retained as intermediate evidence and superseded by the named loaded snapshots below. Screenshots occasionally timed out while advertising was active. The broad audit blocked advertising and tracking requests while retaining the game origin and game service requests. `screenshot-errors.log` records capture failures. The audit scripts and commands remain in this folder; browser profiles and third-party scripts are working evidence and must not be published in the game repository.

## Reproduction and artifact boundaries

Launch with `node browser-audit.cjs browser-profile-interactive` for unfiltered independent-client inspection, or `node broad-audit.cjs` for broad-menu inspection. The scripts import only the installed Playwright package in the tools directory. JSON commands are sent through standard input; Windows terminal input uses carriage returns. `browser-profile-guest-commands.jsonl` and `broad-commands.json` preserve later exact commands; earlier host actions are described above and in snapshots. `assets.json` and `first-party-assets.jsonl` preserve source URLs and SHA-256 hashes. Downloaded reference code/assets remain audit material; implement original code and assets in the football project.

This audit establishes visible menu rules and the tested private-room flow. It does not establish full functional parity: all League career branches, all Gauntlet maps/segments/bosses, full minigame rounds, public rankings, collection earning, terminal H2H/rematch, shared account persistence and reference reconnect behavior remain untested. Proposed football behavior must remain visibly distinct from these unobserved reference branches.
