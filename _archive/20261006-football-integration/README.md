# Superseded Era Eleven material, 2026-10-06

These six originals were retrieved byte-for-byte from the preserved user checkpoint and archived after the complete development commit was pushed and remote `main` was confirmed. Their SHA-256 values, active replacements, reasons, source commit and validation evidence are in [manifest.json](manifest.json).

Archived documents describe earlier behavior and may contain outdated claims or links that require the original repository context. The active [README](../../README.md), [migration inventory](../../docs/MIGRATION.md), [feature matrix](../../docs/FEATURE_MATRIX.md) and [validation record](../../docs/VALIDATION.md) describe the shipped game. The archive has no runtime imports.

To restore a file, preserve the current active file first, verify the archived bytes against `original_sha256`, then copy the archived file to its `original_path`. The same original is available from `source_commit` in Git. Restore the matching historical commit when reproducing an earlier executable game; copying an old document alone does not roll back rules or saved-state versions.

Unique notebook experiments, the local assisted-shot/turnover-aware event module, formation/fatigue rules, permitted player data, upstream research and the earlier Invincible project remain available. Raw audit assets, reference browser profiles and private databases stay in the maintainer work folder.
